# Changelog

All notable project changes are documented here.

## [0.1.0] - 2026-11-28

### Added

- LangGraph orchestration across GitHub, Gmail, and Google Drive MCP servers.
- Local mock servers for deterministic development and tests.
- Real external MCP connections with OAuth and GitHub authentication support.
- Tool discovery, argument validation, retries, timeouts, approvals, persistence,
  resumable runs, traces, metrics, and Streamable HTTP support.
- Live read-only contract verification scripts.
- CI across Python 3.11–3.13 with Ruff, pip-audit, pytest, and coverage checks.
- Security, contribution, pull-request, and issue-template documentation.
